Methodology & Source Verification Protocol

Design Principles

1. Moving Beyond "Percentage Prediction"

Traditional fake-news detection systems return an opaque confidence score like "80% Fake". This gives the user no actionable information about why the content was flagged or what the factual reality actually is. Our system transforms fake-news detection from an ungrounded classification guess into an evidence-assisted verification tool.

2. Source Credibility Hierarchy

External sources are retrieved via permitted live news feeds and knowledge bases, and categorized into transparent credibility tiers:

  • Official Government: Primary legislative, executive, and regulatory portals (.gov, .mil, official state gazettes).
  • Official Organizations: Verified international bodies (WHO, CDC, UN, Red Cross) and dedicated fact-checking units (Reuters Fact Check, AP Fact Check, Snopes).
  • News Articles: Reputable global and national journalistic organizations adhering to journalistic correction standards.
  • Reference Sources: Encyclopedic sources (Wikipedia) providing historical entity definitions and contextual background.

3. Stance & Relationship Classification

Rather than blindly assuming search results confirm a rumor, each snippet is compared with the extracted claim: [SUPPORTS CLAIM], [CONTRADICTS CLAIM], [CONTEXT], or [RELATIONSHIP UNCLEAR].

4. Epistemic Humility

We explicitly acknowledge that TF-IDF + Logistic Regression only measures stylistic writing patterns (sensationalist markers vs. neutral reporting). External evidence provides traceable facts, but the final determination remains in the hands of the human verifier.
